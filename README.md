# Hush
A lightweight native macOS menu bar app for quiet, ordered app launches with per-app delays and network readiness checks.

安静地启动需要的应用。一个轻量、零第三方依赖的原生 macOS 菜单栏工具。

## 功能
- 隐藏启动：默认请求隐藏且不抢焦点，也可按应用关闭隐藏。
- 延迟启动：每项等待 0–300 秒；界面提供常用时间选项。
- 等待网络：每项可独立开启“联网后”，延迟结束后等待对应网络条件连续通过 3 次，再启动应用；默认关闭，保留旧配置开关值。
- 顺序管理：用上下箭头调整顺序，单独启用或暂停应用。
- 启动测试：单项测试或按顺序测试全部，支持停止后续启动。
- 启动记录：保存最近 100 条结果，区分已启动、已请求隐藏、已运行跳过与失败。
- 登录时运行：使用 macOS 的 SMAppService；登录启动时不打开 Hush 管理窗口。

## 使用
1. 打开 `dist/Hush.app`，添加希望登录后运行的应用。
2. 在这些应用自身设置和 macOS 登录项中关闭原有自启动，避免两套入口争用。Hush 不会自动改动其他应用的启动设置。
3. 设置隐藏、延迟、是否等待网络和顺序；点击单行播放按钮或“测试全部”。
4. 测试满意后，开启底部“登录时运行 Hush”；若系统需要批准，点击“前往允许”。
关闭管理窗口后 Hush 留在菜单栏。再次打开应用或选择菜单栏“打开 Hush”可返回列表。

## 行为规则
- Surge、Tailscale 等已识别的网络工具先启动，组内保留列表相对顺序；其余应用按列表从上到下串行启动；当前项延迟和可选网络等待结束，并收到系统启动回调后再进入下一项，不等待其业务初始化完成。
- 已经运行的应用直接跳过，不等待、不隐藏、不切换前台。等待期间用户手动打开的应用也会跳过。
- 单项测试包括该项的等待时间，即使该项暂停也允许测试；全部测试仅处理启用项。
- 网络工具检测基础网络，其他应用检测 HTTPS。HTTPS 每次请求最多 8 秒，两次检测之间等待 5 秒；成功连续计数，失败归零。每项网络等待最多 300 秒，超时不启动该项并记录失败，继续下一项；后续网络项会独立等待。
- 基础网络检测只读本机网络状态：真实 Wi-Fi 或以太网链路活动，同一服务已取得有效 IPv4/IPv6 地址和网关。排除 VPN 虚拟接口、IPv4 自动分配的链路本地地址、仅 IPv6 链路本地地址；不查询 DNS，不访问外网，不要求代理可用。此条件不保证局域网认证已完成或互联网可达。
- HTTPS 检测使用系统 URLSession，经系统代理（如已配置）访问 Apple 的 HTTPS 连通性页面，禁用本地缓存和 Cookie，校验成功页面、状态码与最终地址，避免把登录页或跳转当成可用。不会主动修改 Surge、Tailscale 或代理设置。探测失败可能来自网络、代理或检测站点不可达，不保证所有应用的服务器均可达，也不能保证之后不掉线。
- 已识别的 Surge、Tailscale 自动优先启动，“联网后”可自由勾选：勾选时只等待基础网络，不依赖代理或外网；未勾选则直接按延迟启动。旧配置保留原开关值。其他尚未识别的网络工具仍需按实际依赖安排启动条件。
- 网络等待期间可以停止队列；用户手动打开当前应用后，会在当前探测或重试间隔结束时跳过它。
- 一项失败后继续下一项。系统启动回调超时为 25 秒，超时应用仍可能稍后打开。
- 停止只取消尚未发出的启动请求；已交给系统的启动请求无法撤回，也不会退出已启动的应用。
- 启动期间锁定编辑，避免列表与执行队列不一致。
- 使用书签跟踪应用移动；应用不存在或身份改变时明确提示重新添加。
- 配置原子保存，保存失败不提交界面改动；损坏或更新版本的配置不覆盖，暂停编辑。

## 兼容边界
隐藏对应 macOS 的应用隐藏（类似 ⌘H），不等同于最小化到 Dock。系统提供隐藏启动请求，但第三方应用可能在稍后重新显示窗口或弹出验证界面。Hush 第一版不持续强制隐藏窗口，也不申请辅助功能权限。

最低目标为 macOS 13。当前已在本机 Apple Silicon 环境构建和验证；macOS 13 真机、Intel 真机和真实注销/重新登录仍需验收。当前应用为本地临时签名，未使用 Developer ID 签名或 Apple 公证，不代表可直接面向外部分发。

## 开发
使用 Xcode 打开 `Hush.xcodeproj`。无需安装依赖；`project.yml` 是工程生成源，修改项目结构后可执行 `xcodegen generate`。

```sh
./scripts/build.sh
./scripts/test.sh
```
Release 输出：`build/Build/Products/Release/Hush.app`。将其复制到固定位置后再启用登录启动，启用后不要移动或删除该应用。

数据位置：`~/Library/Application Support/Hush/startup.json` 和 `history.json`。配置和记录仅保存在本机。处理勾选“联网后”的网络工具时只读取本机网络状态；处理勾选的普通应用时才发起 HTTPS 探测，不上传启动列表、记录或凭据。删除应用前请先关闭“登录时运行 Hush”。

## 结构
- `Hush/`：原生界面、菜单栏生命周期、系统启动及登录项服务。
- `HushCore/`：配置与原子保存、可注入的串行调度器、HTTPS 连通性与连续成功等待。
- `Tests/`：调度、取消、运行中跳过、失败继续、持久化等测试。
- `docs/validation.md`：本次验证结果及未验证项目。
- `scripts/make-icon.swift`：应用图标的原生矢量绘制源。

可选真实启动验证：`./scripts/smoke-test.sh` 会短暂启动独立的临时应用并检查隐藏与焦点，结束后退出临时应用。
