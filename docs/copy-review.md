# Hush 文案审查
日期：2026-10-28

## 产品定位
Hush 管理登录后启动的应用，提供隐藏启动、延迟、网络等待与启动顺序设置。文案直接说明功能、当前状态和下一步操作，避免清晨等与使用场景无关的意象。

## 审查范围与调整
已检查简体中文、繁体中文和英文的主窗口、菜单、设置、关于、文件选择、悬停提示、无障碍标签、启动状态、历史记录和错误信息。

| 范围 | 调整 |
| --- | --- |
| 空列表 | 使用“还没有添加应用”，说明添加登录启动应用的用途；日出图标替换为添加应用图标。 |
