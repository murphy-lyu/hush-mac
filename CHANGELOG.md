# Changelog

## 0.4.0 — 2026-10-28
- Introduce a compact monochrome interface with a shared frosted window background and native application icons.
- Add General and About settings with stable tab positions and page-specific titles.
- Add independent Dock and menu bar icon preferences. Dock visibility defaults to off; menu bar visibility defaults to on. Reopening Hush from Finder or Spotlight restores access when both are hidden.
- Support system language, English, Simplified Chinese and Traditional Chinese, with English fallback for unsupported languages. Interface text, progress and existing history update without restarting.
- Simplify the menu bar menu: show launch actions when idle and progress plus cancellation while a launch is in progress.
- Replace the application icon with the selected Paper Stack design, using the original selected image and reproducible macOS size exports.
- Preserve startup configuration, launch ordering, network readiness checks and login-item settings.
